\secn{Coverage Report}
\textbf{Baseline (existing course).} Concrete, geometric, $\mathbb R^n$-centred: fields/complex numbers/axioms (W1), $\mathbb F^n$, $M_{n\times k}$, transpose, matrix products, $\mathcal F(\mathbb F)$ (W2), systems/RREF (W3), sets/vectors/lines/planes (W4--5), span/LI (W6), dot product/projection (W7), subspaces/bases/dimension (W8), coordinates/change of basis (W9, W12), linear maps, composition, range/null space, rank--nullity, inverses (W10--12), determinant via volume (W13), eigen/diagonalization (W14), review (W15). \textbf{The new assessments are an abstract, proof-first version of the same syllabus} (general $\mathbb F$, $\mathbf P_n$, $M_{m\times n}$, $\mathcal L(V,W)$, matrices over $\mathbb C$, ``prove/construct/justify''). Verified absences by keyword search: conjugate transpose, Cramer's rule, multilinear/alternating determinant, Dimension Bound Theorem, isomorphism, $\mathcal L(V,W)$, direct sum, inner-product axioms, $\mathbb F^{\mathbb N}$/shifts, $P_n$ as a working space, subspace tests on matrix/polynomial/function constraint sets.

\textbf{Counting convention.} One \emph{item} = one numbered problem (quizzes/mocks: each lettered part counted; homework: each numbered problem, sub-lists not expanded; definition-recall prompts excluded). \emph{Unique} = first occurrence of a task in the set (order: HW$\to$quiz of the same week $\to$ mocks); \emph{Duplicate} = same task/technique already seen. Counts are by hand, $\pm1$. \emph{New concepts} = Category D; \emph{new patterns} = Category C (Section ``Integration Map'' IDs).
